用户对桌面整洁有严格偏好与纪律要求。在 2026-10-17 交付 Dream Skin 换肤工具时，严厉批评在桌面散落生成多个 `.bat` 批处理文件的做法（原话：*「你别乱放啊 帮我打包好成一个exe 归类好」*）。

**规范与落地方式：**
1. **严禁在桌面平铺多个功能性脚本**：不得在用户桌面散落生成一键启动/一键还原等多份 `.bat` 或 `.ps1` 文件。
2. **单一 EXE 整合交付**：所有换肤、启动、还原、配置类功能，必须整合编译为单一独立的 Windows 原生 GUI 应用程序（如使用 C# + `csc.exe` 编译的无依赖 EXE），放置在 `F:\AI\<工具名>` 目录（遵循工具不落 C 盘铁律）。
3. **桌面只留唯一快捷方式**：桌面仅允许放置一个指向该主程序的单一快捷方式（如 `Dream Skin 换肤总控台.lnk`），界面内部包含所有子功能按钮及状态反馈。
4. **编码规范**：子进程与 GUI 通信时必须显式绑定 UTF-8 管道编码（`StandardOutputEncoding = Encoding.UTF8`），避免 Windows 默认 ANSI/GBK 解码导致日志出现中文乱码（如「鐨偆宸叉垚鍔」）。

**Why:** 用户习惯保持桌面干净清爽，排斥零散散装脚本污染桌面视线，倾向于集成化、单一可执行文件形态的工业级桌面体验。
**How to apply:** 凡涉及向用户交付可交互工具，一律归类到 `F:\AI\`，整合成单一 EXE 后在桌面仅生成一个干净的快捷方式。
